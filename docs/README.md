# docs

분량이 크고 자주 필요하지 않은 참고 자료를 모아 둔다. 항상 지켜야 하는 규칙은 루트 `CLAUDE.md`, 영역별 규칙은 `.claude/rules/`에 있다.

| 문서 | 내용 | 언제 읽는가 |
| --- | --- | --- |
| [`erd.md`](./erd.md) | 테이블 정의와 관계 (ERD) | 엔티티를 추가/수정하거나 테이블 관계를 확인할 때 |
| [`api-spec.md`](./api-spec.md) | 엔드포인트별 요청/응답 명세 | API를 추가/변경하거나 기존 스펙을 확인할 때 |
| [`architecture.md`](./architecture.md) | 패키지 구조, 요청 처리 흐름, 공통 모듈 | 전체 그림이나 공통 모듈의 역할이 필요할 때 |

## 갱신 원칙

- 코드와 문서가 어긋나면 **코드가 진실**이다. 문서를 고치거나, 틀린 부분을 TODO로 표시한다.
- 엔티티를 바꾸면 `erd.md`, API를 바꾸면 `api-spec.md`를 **같은 PR에서** 갱신한다.
- 각 문서 맨 위의 "최종 수정" 날짜를 갱신한다.
